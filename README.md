# 📈 TradingLab Academy - Terminal de Trading Profesional

**TradingLab Academy** es una plataforma web "All-in-One" diseñada para traders que operan en mercados globales. El proyecto transforma una web educativa en una terminal de datos en tiempo real, proporcionando herramientas de análisis técnico, fundamental y de sentimiento en una única interfaz moderna y minimalista.

🔗 **Demo en Vivo:** [https://alejandrogb95.github.io/Freelance/](https://alejandrogb95.github.io/Freelance/)

---

## 🚀 Características Principales

### 🌑 Interfaz "Elite Dark" & UX
* **Menú lateral Glassmorphism:** Navegación ultra-limpia con efecto de cristal desenfocado, optimizada para no interrumpir la visualización de gráficos.
* **Responsive Design:** Adaptación completa a dispositivos móviles, incluyendo un sistema de menú hamburguesa animado que se convierte en "X" al abrirse.
* **Ticker Tape en Tiempo Real:** Barra superior dinámica con las cotizaciones de los principales índices (S&P 500, Nasdaq) y pares de divisas.

### 🛠️ Terminal de Recursos (Recursos.html)
La joya de la corona. Una sección equipada con tecnología de TradingView que incluye:
* **Sentimiento del Mercado:** Velocímetros técnicos para **Oro (XAUUSD)**, BTC y EURUSD.
* **Escáner de Señales (Screener):** Filtro automático que detecta activos en sobreventa, cruces de medias y rupturas de máximos.
* **Análisis Fundamental:** Calendario económico de impacto mundial y News Feed con las últimas noticias del mercado.
* **Mapa de Calor (Heatmap):** Visualización visual de la fuerza relativa en Cripto y Forex.
* **Pulso Global:** Monitor de correlaciones que incluye el Índice del Dólar (DXY) y el VIX (Índice del miedo).

### 📚 Sección Educativa & Captación
* **Roadmap del Éxito:** Un sistema de pasos (01-04) que guía al alumno desde los fundamentos hasta el fondeo institucional.
* **Integración de Vídeo:** Reproductor optimizado para cursos de trading.
* **Gestión de Leads:** Formulario de contacto profesional integrado para soporte y consultas de alumnos.

---

## 🛠️ Stack Tecnológico

* **Lenguajes:** HTML5, CSS3 (Custom Properties, Flexbox, Grid) y JavaScript Vanilla.
* **APIs Financieras:** TradingView Widgets API para datos en tiempo real sin latencia.
* **Estilo:** Efectos de desenfoque (backdrop-filter) y tipografía Inter para máxima legibilidad.
* **Iconografía:** FontAwesome 6 para una interfaz intuitiva.
